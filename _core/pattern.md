# What is a Pattern?

Colloquially, there are a lot of different things we describe as "patterns":

- An aesthetically pleasing arrangement of visuals or audio
- A visual/sonic pattern that involves repetition, or almost repetition
- A visual/sonic pattern that has some amount of non-trivial symmetry
- A creation made from applying a set of mathematical rules

Some of these are very subjective (e.g. aesthetics is a matter of taste).
Some definitions are strict and mathematical.

Yet there are some common themes. Most of the descriptions above imply that a
pattern has some amount of _structure_ or rules that guides the composition.
Repetition/symmetry also seems relevant.

Ultimately, we just need to pick a definition to explore and be 

## Definition of Pattern

For the purposes of this project, I choose the following, intentionally broad
definition:

> **Pattern**
>
> A creation made from a system with two parts:
>
> - **Building Blocks** -- The simplest parts used to build the pattern. This
>   serves as a starting place for making a pattern.
> - **Rules** -- Instructions on how the building blocks interact. This may
>   include ways to combine or modify building blocks. It may also include
>   restrictions on what operations are allowed.

What exactly the above means depends greatly on the context. The other pages
on this website will give many concrete examples.

## Symmetry and Patterns

With this definition of pattern, I view [symmetry](./symmetry) as a _property_
of a pattern, rather than part of the definition. 

Symmetry may show up in patterns in a number of different ways:

- Sometimes a building block has symmetry that influences the symmetry of the
pattern.
- Sometimes the rules introduce symmetry relationships that are inherited by
the pattern.
- Sometimes symmetry emerges indirectly from a pattern due to the particular
combination of building blocks and rules.

In addition to cataloguing patterns, this website will also document notable
symmetry relationships found within each pattern.

## Many Synonyms

Patterns show up in many disciplines, though the terminology varies wildly.
Here are some examples:

🚧 Some of these examples seem too specific for this page... consider revising.

| Context | Building Blocks | Rules |
|---|---|---|
| _Everyday life_ |
| Cooking Recipe | ingredients | instructions |
| _Art_ |
| Wallpaper pattern | A motif drawn in a rectangle | copy and paste the rectangle horizontally and vertically |
| Tiled backgrounds (e.g. for classic video games) | fixed-size tiles (e.g. 16x16 px) | tiles are arranged in a grid (the tilemap)|
| Flip book animation | first drawing | Each drawing is a slight variation on the one before it |
| _Music_ |
| Song Structure | sections (e.g. verse, chorus) | rules for chaining sections (e.g. verse-chorus form) |
| Chord Progression | chords | rules of functional harmony|
| _Math_ |
| Recursive Sequences | base case | recursive case |
| Fractal Curve | initial shape | substitution rules |
| Formal Languages | terminal symbols | non-terminal symbols/production rules |
| Differential Equations | Initial Conditions, Boundary Conditions | Differential Equations |
| _Science_ |
| Hydrocarbons | carbon, hydrogen | carbons can connect to 1-4 other atoms, hydrogen can connect to 1 other atom |
